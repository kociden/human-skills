# human-skills

人間のための skill 集。

AIエージェントの skill と同じ形で書く。1つの skill = 1つのフォルダ、中に `SKILL.md`。
冒頭の `description` に「どんな時に使うか」を書いておき、その場面が来たら開いて、書いてある手順のとおりにやる。

## skill の一覧

| skill | いつ使う |
|---|---|
| [ask-directly](skills/ask-directly/SKILL.md) | 欲しいものがあるのに、頼むのをためらった時 |

## 足し方

1. `skills/<名前>/SKILL.md` を作る(名前は英小文字とハイフン)。
2. 冒頭に次を書く。

   ```
   ---
   name: <名前>
   description: <どんな時に使うか>
   ---
   ```

3. 本文は「なぜ効くのか → やり方 → やらないこと → 今日やること」の順で書く。根拠があれば出典も書く。
4. 上の一覧に1行足す。
