# はっきり頼む

**欲しいものは、はっきり頼む。気まずく感じるくらい何度も。**

## なぜ効くのか

- 人は「相手がOKしてくれる確率」をかなり低く見積もる。Flynn と Lake の実験(2008)では、見知らぬ人に頼みごとをする前に「何人に頼めば足りるか」を予想させた。実際には予想のおよそ半分の人数で足りた。
- 断られる気まずさは大きく感じ、断る側の気まずさは小さく感じる。実際は逆で、断る方もけっこう気まずい。だからOKが出やすい。
- **割に合う賭け**: 断られても失うのは数秒の気まずさだけで、元の場所に戻るだけ。OKならお金・人のつながり・チャンス・時間が手に入る。
- 自分の努力には上限がある。頼めば、他人の力・知恵・好意を借りられる。こちらの方がずっと大きい。
- 頼むほど怖さが減る。続けると効いてくる。

例: スティーブ・ジョブズは12歳のとき、HPのビル・ヒューレットの番号を電話帳で調べて電話し、部品をくださいと頼んだ。部品と夏のアルバイトの両方をもらえた。本人はのちに「頼む人と頼まない人の差が、やる人と夢を見るだけの人の差だ」という趣旨のことを言っている。

## やり方

1. **欲しいものを1行で書く。** 「何を・いつまでに・どのくらい」。ぼんやりしていると頼めない。
2. **頼める相手を3人書き出す。** 「この人は無理だろう」と思う人も消さない。その見積もりが一番あてにならない。
3. **短く、はっきり頼む。** 遠回しに匂わせない。決まった型は下にある。
4. **断られたら「ありがとう」で終わる。** 理由を聞いてよければ聞き、次に生かす。食い下がらない。
5. **数を記録する。** 頼んだ数・OKの数をメモする。率がわかると怖さが減る。

## 頼み方の型

```
〇〇さん、お願いがあります。
[欲しいこと] をしてもらえませんか?
[理由を1行]。
[相手の手間を小さくする一言: 5分で済みます / 断ってもらっても大丈夫です]
```

- 理由は短くていい。「〜なので」があるだけでOKが出やすくなる。
- 相手のやることを小さく、はっきりさせる(「ご意見ください」ではなく「この画面を見て、わかりにくい所を1つ教えてください」)。
- 逃げ道を残す(「難しければ全然大丈夫です」)。相手が楽になり、関係も傷まない。

## やらないこと

- しつこく何度も同じ人に頼む。断られたら、その件は終わり。
- 相手が断りにくい立場(部下・年下・弱い立場)なのを利用する。
- もらうだけで終わる。お礼を言い、結果を伝え、いつか返す。

## 今日やること

**1つだけ頼む。** 小さくていい。頼んだら、OKでもNOでも記録する。
